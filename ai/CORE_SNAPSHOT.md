# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบันของเรื่อง
- **เวลา**: หลังแต่งงานขององค์ชายรองกับหลี่หรงประมาณ 4+ เดือน
- **เหตุการณ์หลักล่าสุด**: คดีแม่ทัพหยาง + การตั้งกรมสืบสวนพิเศษ

## สรุปเหตุการณ์สำคัญ (ไม่ตกหล่น)

### 1. จุดเริ่มต้นคดี
- แม่ทัพหยางถูกกล่าวหาว่าถอยทัพโดยไม่มีพระบรมราชานุญาต
- กำหนดประหารใน 43 วัน
- องค์ชายรองไปเยี่ยมจวนอู่ (พ่อตา) แสร้งบังเอิญ
- ได้ข้อมูลจากแม่ทัพอู่เรื่องเสบียงปนทรายจากทหารที่เคยไปตะวันตก

### 2. การสอบสวนที่จวนอู่
- เรียกจางเหลียง (ทหาร) มาสอบถามทางประตูหลัง
- ได้ข้อมูลเบื้องต้นเรื่องทรายปนเสบียง + คนนำส่งแปลกหน้า
- องค์ชายรองตัดสินใจไปด่านเหยียนเหมิน
- ขอหน่วยเขี้ยวพยัคฆ์ 100 นายจากแม่ทัพอู่ ให้แฝงตัวทยอยเดินทาง
- เข้าเฝ้าฮ่องเต้ก่อน ได้รับอนุญาต (ต้องกลับภายใน 1 เดือน)

### 3. การเดินทางและการสอบสวนที่ด่านเหยียนเหมิน
- ใช้เวลาเดินทางกว่า 10 วัน
- ปลอมตัวเป็นพ่อค้าพลอย
- หน่วยเขี้ยวพยัคฆ์เก็บหลักฐาน:
  - กระสอบเสบียงทั้งที่เปิดแล้วและยังไม่เปิด (มีทรายปน)
  - ทรายละเอียดสีขาว มีเฉพาะที่ชายหาดทางตะวันออกของเมืองหลวง (ใกล้ฝ่ายการท่า)
  - บัญชีน้ำหนักผิดปกติ + รอยแก้ไข
  - คนส่งเสบียงแปลกหน้า 2 ชุด (โดยเฉพาะชายแผลเป็นคิ้วซ้าย)
- พยานบุคคลสำคัญ: นายกองจาง ที่แสร้งเป็นขอทานในหมู่บ้าน (เล่าเหตุการณ์วันที่ถอยทัพ + การหาย/ตายผิดปกติของพยานอื่น)

### 4. การกลับเมืองหลวง + ลานประหาร
- ขบวน 114 ชีวิตควบกลับแบบเร่งด่วน
- กรมอาญาเปลี่ยนเวลาประหารเป็นตอนเช้า
- หยางเฟยนำกำลังล้อมลานประหาร + หลี่หรงไปด้วย
- องค์ชายรองยิงธนูเสียบไม้สัญญาน + ยิงมือเพชฌฆาต
- ใช้กระบี่ในฝักกระแทกแนวทหารกรมอาญา
- ราชโองการมาถึง: ยกเลิกประหาร + เรียกประชุมด่วน

### 5. ท้องพระโรง
- เปิดกระสอบเสบียงต่อหน้าขุนนาง → อื้ออึง
- ชี้แจงบัญชีอย่างละเอียด
- พยานนายกองจางให้การ
- อู่จงลากชายแผลเป็นเข้ามา → ถูกขู่จนสารภาพว่าเกี่ยวข้องกับอ๋องฉี
- อ๋องฉีตัดหาง โยนความผิดทั้งหมดให้เจ้ากรมอาญา
- ฮ่องเต้ประกาศว่าหลักฐานพอพิสูจน์ความบริสุทธิ์ของแม่ทัพหยางแล้ว
- เจ้ากรมอาญาถูกลงโทษเพิ่มเพราะสั่งมือปราบหมายทำร้ายเชื้อพระวงศ์
- องค์ชายรองเสนอตั้ง **กรมสืบสวนพิเศษ** โดยตนเป็นผู้ดูแล
- ฮ่องเต้อนุญาต (กองกำลังไม่เกิน 500 นาย, รายงานตรงต่อฮ่องเต้, เน้นสืบข้อเท็จจริง)
- รัชทายาทเป็นผู้ร่างโครงสร้าง

## ตัวละครสำคัญที่เกี่ยวข้องในอาร์คนี้
- องค์ชายรอง (ตัวเอก)
- หลี่หรง (พระชายา)
- หยางเฟย (บุตรสาวแม่ทัพหยาง, ชุดเขียว + ริบบิ้นแดง, หอก)
- แม่ทัพหยาง
- แม่ทัพอู่ + ฮูหยินอู่
- อู่จง
- อ๋องฉี (ถูกพาดพิงหนัก)
- เจ้ากรมอาญา (ถูกถอดตำแหน่ง + ขัง)
- นายกองจาง (พยานสำคัญ)
- ชายแผลเป็นคิ้วซ้าย (คนส่งเสบียง)
- ขันทีเจิ้ง (เจิ้งกงๆ)

## สถานที่สำคัญ
- จวนอู่
- ด่านเหยียนเหมิน (ป้อม, คลังเสบียง, โรงเตี๊ยม, หมู่บ้านนอกด่าน)
- ลานประหารเมืองหลวง
- ท้องพระโรง
- ห้องทรงงาน
- ฝ่ายการท่า (แหล่งทราย)
