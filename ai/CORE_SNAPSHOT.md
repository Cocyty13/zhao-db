# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองอยู่ที่ **สำนักง้อไป๊**
- พาหลี่หรง + นางกำนัลขึ้นเขา (ทหารรอที่ตีนเขา)
- พบเจ้าสำนักเซี่ยชิงเยว่และผู้อาวุโสแล้ว

## สถานที่สำคัญที่เกี่ยวข้อง
- **สำนักง้อไป๊** — สำนักสตรีบนภูเขา (ปัจจุบันอยู่ที่นี่)
- **เมืองชิงเหอ** — เมืองการค้า จุดแวะพักก่อนขึ้นเขา
- เมืองหลวง / จวนองค์ชายรอง
- ด่านเหยียนเหมิน (อาร์คแม่ทัพหยาง)

## อาจารย์ขององค์ชายรอง
- **ไป๋หลาน** และ **เฟยหลง**
- ระดับตำนานของง้อไป๊ บูตึ๊ง และยุทธภพ
- รักกันแต่ถูกกีดกัน → ออกจากสำนัก หายจากยุทธภพ

## ตัวละครสำนักง้อไป๊
- เจ้าสำนัก: เซี่ยชิงเยว่
- อาจารย์ทวด: ไป๋เหิง, ชิงหลัน
- ศิษย์เอก: ซูหยิน
- ศิษย์น้อง: เหย่ชิง
