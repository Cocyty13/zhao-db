# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองนำทัพล่วงหน้า 4,500 นาย + นักยุทธ์จากสำนักต่าง ๆ ≈110+ คน
- ปัจจุบันอยู่ที่ **เมืองหยานเฉิง**
- พรุ่งนี้เช้าเคลื่อนต่อไปยัง **ด่านเหยียนเหมิน** (อีก 2–3 วัน)
- หลี่หรงอยู่กับซัวเหยาในเมืองหลวง
- แม่ทัพอู่กำลังเตรียมทัพหลวงตามมา

## กำลังด้านหน้า
- ด่านเหยียนเหมิน: ≈8,000–9,000 นาย (แม่ทัพหยางบัญชาการอยู่)
- เสบียงด่าน: อยู่ได้อีก ≈20–25 วัน (นับจากตอนเริ่มเดินทาง)
- ทัพชีเชี่ย: 20,000 นาย (อาจระดมได้ถึง 40,000 หากไม่แตกแยก)

## โครงสร้างกรมสืบสวนหลวง
- เจ้ากรม: องค์ชายรอง
- หัวหน้าฝ่ายสืบคดี: หลี่หรง / รอง: เหวินชิง
- หัวหน้าฝ่ายมือปราบ: หยางเฟย / รอง: จ้าวเฉิง
