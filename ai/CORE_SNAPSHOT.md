# CORE SNAPSHOT

## ตัวเอก
**องค์ชายรอง**  
- อดีต: แสร้งเป็นคุณชายเสเพล ขี้เมา เจ้าสำราญ เพื่อปกปิดตัวตน  
- จุดเปลี่ยน: คืนงานแต่งรัชทายาท เกิดเหตุลอบสังหาร → ถูกบังคับให้เปิดเผยตัว  
- พบและช่วยหลี่หรงในคืนนั้น  
- อาจารย์ที่แท้จริง: สิทธิ์ (สำนักเง้อ) และ สิทย์ (สำนักบูตึ๊ง) ซึ่งเป็นศิษย์พี่ของเจ้าสำนัก → ตัวเองเป็นศิษย์หลาน  
- หลังเหตุการณ์: ฮองเฮาจัดงานชมบุปผา → พูดคุยกับหลี่หรงและหยางเฟย → ฮ่องเต้ประกาศราชโองการแต่งงานในคืนนั้น  

## สถานะปัจจุบัน
- แต่งงานกับหลี่หรงแล้ว  
- เกี่ยวข้องกับคดีแม่ทัพหยาง (ถูกกล่าวหาถอยทัพ) และปัญหาเสบียงปนทราย  

## ตัวละครสำคัญที่เกี่ยวข้อง
- หลี่หรง (พระชายา)  
- หยางเฟย (ฉลาดหลักแหลม พบในงานชมบุปผา)  
- รัชทายาท (เหตุลอบสังหารในคืนงานแต่ง)  
- อาจารย์สิทธิ์ & สิทย์  
- ฮองเฮา / ฮ่องเต้
