# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองแต่งงานกับหลี่หรงแล้ว
- เพิ่งจบคดีแม่ทัพหยางเบื้องต้น + ตั้งกรมสืบสวนพิเศษ
- ปัจจุบันพาหลี่หรงเดินทางมาเที่ยวเมืองชิงเหอ (เมืองการค้า)
- พบเหย่ชิง (ศิษย์น้องจากง้อไป๊) ที่ตลาดชิงเหอ

## ประวัติตัวเอก + เส้นทางสำนัก (สำคัญ)
- อดีตแสร้งเป็นคุณชายเสเพลเพื่อปกปิดตัวตน
- **คืนงานเลี้ยงรัชทายาท**: เกิดเหตุลอบสังหาร → ถูกบังคับให้เปิดเผยตัว
- พบและช่วยหลี่หรงในคืนนั้น
- **อาจารย์ที่แท้จริง**: 
  - สิทธิ์ (สำนักเง้อ)
  - สิทย์ (สำนักบูตึ๊ง)
  - ทั้งสองเป็นศิษย์พี่ของเจ้าสำนักปัจจุบัน → ออกจากสำนักไปแต่งงานกัน แล้วหายจากยุทธภพ
  - องค์ชายรองจึงเป็นศิษย์หลาน (ไม่ใช่ศิษย์ตรง)
- ในคืนลอบสังหาร มีศิษย์ง้อไป๊มาด้วย รวมถึง **เหย่ชิง** ที่มากับอาจารย์อา/เจ้าสำนัก และช่วยปะทะคนร้าย

## อาร์คแม่ทัพหยาง (จบเบื้องต้น)
- สอบสวนที่ด่านเหยียนเหมิน → เปิดหลักฐานในท้องพระโรง
- แม่ทัพหยางพ้นมลทินเบื้องต้น
- อ๋องฉีตัดหาง / เจ้ากรมอาญาถูกลงโทษ
- ตั้งกรมสืบสวนพิเศษ (≤500 นาย)

## เหตุการณ์ปัจจุบัน (เมืองชิงเหอ)
- ออกจากจวนแบบฉุกเฉิน ใช้เวลาเดินทาง 5 วัน
- พักโรงเตี๊ยมชื่อดังในเมือง
- เดินตลาด ซื้อปิ่น ผ้าแพร ยาสมุนไพร
- พบเหย่ชิงโดยบังเอิญ
