# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- กรมสืบสวนหลวงดำเนินงานมาแล้ว 3+ เดือน
- ข่าวด่วน: ทัพชีเชี่ย 20,000 นายเริ่มรวมกำลังที่ด้านหน้าด่านเหยียนเหมิน
- องค์ชายรองกำลังไปจวนสกุลหยางเพื่อคุยกับรองแม่ทัพหยางเฉิน

## เส้นทางเมืองหลวง → ด่านเหยียนเหมิน
1. เมืองหลวง → ค่ายหลงหยาง (1.5–2 วัน)
2. ค่ายหลงหยาง → เมืองชิงเหอ (3–4 วัน)
3. เมืองชิงเหอ → เมืองหยานเฉิง (2 วัน)
4. เมืองหยานเฉิง → ด่านเหยียนเหมิน (2–3 วัน)
- รวมประมาณ 10–12 วันสำหรับทัพพร้อมเสบียง
