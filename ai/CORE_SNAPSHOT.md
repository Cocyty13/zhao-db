# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองและหลี่หรงพักอยู่ที่สำนักง้อไป๊มาแล้วสองสามคืน
- หลี่หรงสนิทกับเหย่ชิงและซูหยินอย่างรวดเร็ว ราวกับพี่น้อง

## สำนักง้อไป๊
- เจ้าสำนัก: เซี่ยชิงเยว่
- อาจารย์ทวด: ไป๋เหิง, ชิงหลัน
- ศิษย์เอก: ซูหยิน
- ศิษย์: เหย่ชิง

## อาจารย์ขององค์ชายรอง
- ไป๋หลาน และ เฟยหลง (ตำนานที่หายจากยุทธภพ)
