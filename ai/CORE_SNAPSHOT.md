# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองแต่งงานกับหลี่หรงแล้ว
- เพิ่งจบคดีแม่ทัพหยางเบื้องต้น + ตั้งกรมสืบสวนพิเศษ
- ปัจจุบันพาหลี่หรงเดินทางมาเที่ยวเมืองชิงเหอ
- พบเหย่ชิง (ศิษย์น้องจากง้อไป๊) ที่ตลาดชิงเหอ

## ประวัติตัวเอก + เส้นทางสำนัก (สำคัญ)
- อดีตแสร้งเป็นคุณชายเสเพลเพื่อปกปิดตัวตน
- **คืนงานเลี้ยงรัชทายาท**: เกิดเหตุลอบสังหาร → ถูกบังคับให้เปิดเผยตัว
- พบและช่วยหลี่หรงในคืนนั้น

### อาจารย์ขององค์ชายรอง
- **ไป๋หลาน** และ **เฟยหลง**
- เป็นระดับตำนานของสำนักง้อไป๊และบูตึ๊ง รวมถึงยุทธภพในยุคนั้น
- ทั้งสองรักกัน แต่ถูกกีดกัน
- จึงออกจากสำนักไปใช้ชีวิตด้วยกัน แล้วหายไปจากยุทธภพ
- องค์ชายรองเป็นศิษย์ของทั้งสองท่าน → นับเป็นศิษย์หลานของเจ้าสำนักปัจจุบัน

### อาจารย์อา
- เจ้าสำนักง้อไป๊ปัจจุบัน = อาจารย์ของเหย่ชิง

## เหตุการณ์ปัจจุบัน (เมืองชิงเหอ)
- พบเหย่ชิงโดยบังเอิญ
- กำลังสนทนาเรื่องสำนักและอาจารย์
