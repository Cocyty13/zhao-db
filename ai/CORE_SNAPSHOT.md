# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองแต่งงานกับหลี่หรงแล้ว (ประมาณ 4+ เดือน)
- เพิ่งจบคดีแม่ทัพหยางเบื้องต้น
- ได้รับอนุญาตตั้ง **กรมสืบสวนพิเศษ** โดยตนเป็นผู้ดูแล (กองกำลังไม่เกิน 500 นาย รายงานตรงต่อฮ่องเต้)

## ประวัติตัวเอก (องค์ชายรอง)
- อดีตแสร้งเป็นคุณชายเสเพล ขี้เมา เจ้าสำราญ เพื่อปกปิดตัวตน
- คืนงานแต่งรัชทายาทเกิดเหตุลอบสังหาร → ถูกบังคับให้เปิดเผยตัว
- พบและช่วยหลี่หรงในคืนนั้น
- อาจารย์ที่แท้จริง: สิทธิ์ (สำนักเง้อ) และ สิทย์ (สำนักบูตึ๊ง) เป็นศิษย์พี่ของเจ้าสำนัก → ตัวเองเป็นศิษย์หลาน
- หลังเหตุการณ์ ฮองเฮาจัดงานชมบุปผา → พูดคุยกับหลี่หรงและหยางเฟย → ฮ่องเต้ประกาศราชโองการแต่งงานในคืนนั้น

## สรุปอาร์คแม่ทัพหยาง (จบเบื้องต้น)
1. แม่ทัพหยางถูกกล่าวหาถอยทัพ → กำหนดประหาร
2. องค์ชายรองไปจวนอู่ ได้ข้อมูลเสบียงปนทราย
3. ขึ้นด่านเหยียนเหมิน สอบสวน + เก็บหลักฐาน (กระสอบทราย, บัญชี, พยาน)
4. ทรายมาจากชายหาดใกล้เมืองหลวง (ฝ่ายการท่า)
5. กลับทันเวลา ขัดขวางการประหารที่ลานประหาร
6. เปิดหลักฐานในท้องพระโรง → แม่ทัพหยางพ้นมลทินเบื้องต้น
7. อ๋องฉีตัดหางโยนความผิดให้เจ้ากรมอาญา
8. เจ้ากรมอาญาถูกลงโทษหนัก
9. ตั้งกรมสืบสวนพิเศษ

## ตัวละครหลักที่เกี่ยวข้อง
- หลี่หรง (พระชายา)
- หยางเฟย (บุตรสาวแม่ทัพหยาง)
- แม่ทัพหยาง
- แม่ทัพอู่ + ฮูหยินอู่
- อู่จง
- อ๋องฉี
- รัชทายาทหลี่หยาง + พระชายาเซี่ยหยุน
- ฮ่องเต้
