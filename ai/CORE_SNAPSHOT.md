# CORE SNAPSHOT (อัปเดตล่าสุด)

## สถานะปัจจุบัน
- องค์ชายรองแต่งงานกับหลี่หรงแล้ว
- เพิ่งจบคดีแม่ทัพหยางเบื้องต้น + ตั้งกรมสืบสวนพิเศษ
- กลับจวนแล้ว เริ่มเพิ่มการเฝ้าระวังเพราะเหยียบหน้าหลายฝ่าย
- รับ **เสิ้นไป๋อวี่** เข้ามาเป็นองครักษ์ส่วนตัวของหลี่หรง

## ประวัติตัวเอก
- เคยแสร้งเป็นคุณชายเสเพลเพื่อปกปิดตัวตน
- เปิดเผยตัวในคืนลอบสังหารรัชทายาท
- อาจารย์: สิทธิ์ (สำนักเง้อ) และ สิทย์ (สำนักบูตึ๊ง)

## อาร์คแม่ทัพหยาง (จบเบื้องต้น)
- สอบสวนที่ด่านเหยียนเหมิน → เปิดหลักฐานในท้องพระโรง
- แม่ทัพหยางพ้นมลทินเบื้องต้น
- อ๋องฉีตัดหาง / เจ้ากรมอาญาถูกลงโทษ
- ตั้งกรมสืบสวนพิเศษ (กองกำลัง ≤500 นาย)

## เหตุการณ์ล่าสุด
- กลับจวนหลังออกจากวัง
- สั่งเพิ่มการเฝ้าระวังจวน (โดยเฉพาะห้องพระชายา)
- รับเสิ้นไป๋อวี่เข้ามาประจำการ
