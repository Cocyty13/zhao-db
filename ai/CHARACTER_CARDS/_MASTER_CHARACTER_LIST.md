# MASTER CHARACTER LIST (อัปเดตล่าสุด)

## ราชวงศ์
- องค์ชายรอง
- หลี่หรง
- ซัวเหยา
- ฮ่องเต้ / รัชทายาท / พระชายาเซี่ยหยุน
- อ๋องฉี

## ตระกูลอู่ / หยาง
- แม่ทัพอู่, อู่เหวินเฉิง, ฮูหยินอู่
- แม่ทัพหยาง, หยางเฉิน, หยางเฟย

## คนในจวน
- หลี่เชี่ย, เสิ้นอวี้หลัน, เสิ้นไป๋อวี่/ไป๋หลี่, อู่จง

## สำนักง้อไป๊
- เจ้าสำนัก **เซี่ยชิงเยว่**
- อาจารย์ทวด **ไป๋เหิง**
- อาจารย์ทวด **ชิงหลัน**
- ศิษย์เอก **ซูหยิน**
- ศิษย์ **เหย่ชิง**

## อาจารย์ขององค์ชายรอง
- **ไป๋หลาน** และ **เฟยหลง** (ตำนานที่หายจากยุทธภพ)
