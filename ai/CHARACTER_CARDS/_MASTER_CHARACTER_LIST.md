# MASTER CHARACTER LIST (อัปเดตล่าสุด)

## ราชวงศ์
- องค์ชายรอง (เจ้ากรมสืบสวนหลวง)
- หลี่หรง (หัวหน้าฝ่ายสืบคดี)
- ซัวเหยา
- ฮ่องเต้ / รัชทายาท / พระชายาเซี่ยหยุน
- อ๋องฉี

## ตระกูลอู่ / หยาง
- แม่ทัพอู่, อู่เหวินเฉิง, ฮูหยินอู่
- แม่ทัพหยาง, หยางเฉิน (รองแม่ทัพ), หยางเฟย (หัวหน้าฝ่ายมือปราบ)

## คนในจวน / กรม
- หลี่เชี่ย, เสิ้นอวี้หลัน, เสิ้นไป๋อวี่/ไป๋หลี่, อู่จง
- เหวินชิง (รองหัวหน้าฝ่ายสืบคดี)
- จ้าวเฉิง (รองหัวหน้าฝ่ายมือปราบ)

## สำนักง้อไป๊
- เจ้าสำนักเซี่ยชิงเยว่
- อาจารย์ทวดไป๋เหิง, ชิงหลัน
- ซูหยิน (ศิษย์เอก)
- เหย่ชิง
- ชิงเซวียน (ศิษย์อาวุโส นำคนมาสมทบ)

## อาจารย์ขององค์ชายรอง
- ไป๋หลาน และ เฟยหลง

## ตัวแทนสำนักที่มาสมทบ
- เหอเจิ้น (บู้ตึ้ง)
- เหลียงฟง (หัวซาน)
- เม่อชิง (คุนหลุน)
- ฮุ่ยหยวน (เส้าหลิน)
