# ACTIVE PLOT

## สถานะปัจจุบัน (หลังเปิดกรม 3 เดือน)
- กรมสืบสวนหลวงดำเนินงานมาได้สามเดือน
- คดีเล็กปิดไปจำนวนหนึ่ง
- คดีใหญ่เริ่มคืบหน้า
- ฮ่องเต้และขุนนางพอใจกับผลงาน

## โครงสร้างหลัก
- เจ้ากรม: องค์ชายรอง
- ฝ่ายสืบคดี: หลี่หรง (หัวหน้า) + หลินเซี่ย (ผู้ช่วย)
- ฝ่ายมือปราบ: หยางเฟย (หัวหน้า) + จ้าวเฉิง (ผู้ช่วย)
