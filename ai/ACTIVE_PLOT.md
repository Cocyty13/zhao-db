# ACTIVE PLOT

## เหตุการณ์ปัจจุบัน
- ทัพล่วงหน้าถึงเมืองหยานเฉิงแล้ว
- นักยุทธ์จาก 5 สำนักมารวมตัว ≈110+ คน
- พรุ่งนี้เช้าเคลื่อนสู่ด่านเหยียนเหมิน

## ผู้ร่วมเดินทางหลัก
- องค์ชายรอง
- อู่จง
- หยางเฟย
- เหย่ชิง
- นักยุทธ์จากง้อไป๊ บู้ตึ้ง หัวซาน คุนหลุน เส้าหลิน

## เส้นทางที่ผ่านแล้ว
1. เมืองหลวง → ค่ายหลงหยาง
2. ค่ายหลงหยาง → เมืองชิงเหอ
3. เมืองชิงเหอ → เมืองหยานเฉิง (ปัจจุบัน)
4. เมืองหยานเฉิง → ด่านเหยียนเหมิน (กำลังจะไป)
