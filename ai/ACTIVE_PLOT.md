# ACTIVE PLOT

## เหตุการณ์ปัจจุบัน (ด่านเหยียนเหมิน)
- ถึงด่านแล้ว พบแม่ทัพหยาง
- ไม่ยกธงมังกรขึ้นกำแพง (ปกปิดกำลังเสริม)
- เริ่มสร้างเครื่องยิงหินหลังแนว + พรางเครื่องยิงเกาทัณฑ์
- ทดสอบลูกธนูแบบหลี่หรงสำเร็จ
- ปฏิบัติการข่าวลวง: อู่จงแกล้งโวยวายเรื่องเสบียงทราย + ทัพหลวงมาแค่ 2,000 เพื่อให้สายลับพ่อค้าได้ยิน

## แผนปัจจุบัน
- ตั้งรับโดยใช้กำแพงเป็นหลัก
- เร่งสร้างเครื่องยิงและลูกธนูเพิ่มโดยไม่ให้ด้านนอกเห็น
- ล่อให้ชีเชี่ยบุกเร็วขึ้นเพราะคิดว่าด่านยังไม่มีกำลังเสริมและเสบียงมีปัญหา
- รอทัพหลวงของแม่ทัพอู่

## ผู้ร่วมอยู่ที่ด่าน
- องค์ชายรอง
- แม่ทัพหยาง
- หยางเฟย
- อู่จง
- เหย่ชิง
- นักยุทธ์จากง้อไป๊ บู้ตึ้ง หัวซาน คุนหลุน เส้าหลิน
