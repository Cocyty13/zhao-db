# ACTIVE PLOT

## สถานะปัจจุบัน
- อยู่ที่สำนักง้อไป๊มาแล้วสองสามคืน
- หลี่หรงเริ่มสนิทกับเหย่ชิงและซูหยิน จนดูเหมือนพี่น้อง
- องค์ชายรองได้พูดคุยกับผู้อาวุโสและเจ้าสำนักแล้ว

## ความสัมพันธ์ที่พัฒนา
- หลี่หรง ↔ เหย่ชิง ↔ ซูหยิน : สนิทกันอย่างรวดเร็ว
- ผู้อาวุโสรับรู้เรื่องปรานและวิชาขององค์ชายรองแล้ว
