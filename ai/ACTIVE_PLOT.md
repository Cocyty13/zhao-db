# ACTIVE PLOT

## สถานะปัจจุบัน
- **กรมสืบสวนหลวง** สถาปนาอย่างเป็นทางการแล้ว
- หลี่หรง: เลขาสำนักสืบสวน / ผู้ช่วยฝ่ายบุ๋น
- หยางเฟย: หัวหน้ามือปราบ / ผู้ช่วยฝ่ายบู๊
- สถานที่: สำนักองครักษ์เก่าชานเมือง (ซ่อมแซมเสร็จ)

## โครงสร้างบุคลากร
- หน่วยมือปราบ: คัดจากกองทหารตระกูลหยาง + ตระกูลอู่
- ฝ่ายบุ๋น: จากสำนักบัณฑิต ที่หลี่หรงสอบคัดเอง
- กำลังรวมไม่เกิน 500 นายตามที่ฮ่องเต้กำหนด
