# ACTIVE PLOT

## เหตุการณ์ปัจจุบัน (ด่านเหยียนเหมิน)
- ถึงด่านแล้ว พบแม่ทัพหยาง
- ไม่ยกธงมังกรขึ้นกำแพง
- เริ่มสร้างเครื่องยิงหิน + พรางเครื่องยิงเกาทัณฑ์
- ทดสอบลูกธนูแบบหลี่หรงสำเร็จ
- ปฏิบัติการข่าวลวงผ่านอู่จง (เสบียงทราย + ทัพหลวงมาแค่ 2,000)
- นักยุทธ์ 5 สำนักพร้อมรับการจัดวางตำแหน่ง

## ฝ่ายยุทธภพ
- ง้อไป๊ (ชิงเซวียน, 35) / บู้ตึ้ง (เหอเจิ้น, 28) / หัวซาน (เหลียงฟง, 16) / คุนหลุน (เม่อชิง, 12) / เส้าหลิน (ฮุ่ยหยวน, 21)
- ใช้ในจุดคล่องตัว: ลาดตระเวนกลางคืน, สกัดหน่วยกล้าตาย, จุดล่อแหลมบนกำแพง

## แผนปัจจุบัน
- ตั้งรับโดยใช้กำแพงเป็นหลัก
- ทำให้ศัตรูคิดว่าด่านยังไม่มีกำลังเสริมและเสบียงมีปัญหา
- ล่อให้บุกเร็วขึ้น
- รอทัพหลวงของแม่ทัพอู่
