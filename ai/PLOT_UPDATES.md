# PLOT UPDATES (บันทึกฉากสำคัญ)

## อาร์คหลังแต่งงาน – คดีแม่ทัพหยาง (สรุปครบ)

### ช่วงจวนอู่
- แจ้งข่าวแม่ทัพหยางถูกตั้งโทษประหาร
- สอบถามจางเหลียงเรื่องเสบียงปนทราย
- ตัดสินใจไปด่าน + ขอหน่วยเขี้ยวพยัคฆ์ 100 นาย
- เข้าเฝ้าฮ่องเต้ ได้รับอนุญาต

### ช่วงด่านเหยียนเหมิน
- ปลอมตัวพ่อค้าพลอย
- เก็บหลักฐานกระสอบ + ทราย + บัญชี
- พบว่าทรายมาจากชายหาดใกล้เมืองหลวง (ฝ่ายการท่า)
- พบพยานนายกองจางในหมู่บ้าน

### ช่วงลานประหาร
- กลับทันเวลาแบบเฉียดฉิว
- ยิงธนูขัดขวางการประหาร
- หลี่หรง + หยางเฟยอยู่ที่เกิดเหตุ
- ราชโองการยกเลิกประหาร

### ช่วงท้องพระโรง
- เปิดหลักฐานทั้งหมด
- อ๋องฉีตัดหาง
- เจ้ากรมอาญาถูกลงโทษหนัก
- ตั้งกรมสืบสวนพิเศษ (องค์ชายรองดูแล, ≤500 นาย)

### หลังที่ประชุม
- แม่ทัพหยางถูกปลดจากสถานะนักโทษ
- องค์ชายรองเข้าเฝ้าห้องทรงงานกับหลี่หรง
- มีบทสนทนาเบา ๆ กับรัชทายาทเรื่องรับคนเข้าจวน
