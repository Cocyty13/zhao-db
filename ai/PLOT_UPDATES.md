# PLOT UPDATES

## ความสัมพันธ์ทางสำนัก (แก้ไขล่าสุด)

- **อาจารย์ขององค์ชายรอง** = ศิษย์พี่ของเจ้าสำนักปัจจุบัน ที่ออกจากสำนักไปแต่งงานและหายจากยุทธภพ
- **อาจารย์อา** = เจ้าสำนักง้อไป๊ปัจจุบัน = **อาจารย์ของเหย่ชิง**
- องค์ชายรอง = ศิษย์หลาน
- เหย่ชิง = ศิษย์น้องตามลำดับรุ่น

## คืนลอบสังหาร
- เหย่ชิงมากับอาจารย์อา (เจ้าสำนักง้อไป๊)
- ช่วยปะทะคนร้าย
- หลังจากนั้นองค์ชายรองถึงได้รู้ความจริงเรื่องลำดับศิษย์ของตน
