# PLOT UPDATES

## จุดสำคัญที่ต้องจำต่อเนื่อง

### คืนลอบสังหาร (งานเลี้ยงรัชทายาท)
- องค์ชายรองถูกบังคับให้เปิดเผยตัว
- ช่วยหลี่หรงไว้
- เหย่ชิง + คนจากง้อไป๊อยู่ที่งานด้วย ช่วยปะทะคนร้าย
- หลังจากนั้นถึงได้รู้ความจริงเรื่องอาจารย์ของตน

### ความสัมพันธ์ทางสำนัก (สะกดถูกต้อง)
- อาจารย์ขององค์ชายรองเป็น **ศิษย์พี่** ของเจ้าสำนักง้อไป๊และบูตึ๊ง
- ออกจากสำนักไปแต่งงาน หายจากยุทธภพ
- องค์ชายรอง = ศิษย์หลาน
- เหย่ชิง = ศิษย์น้องตามลำดับรุ่น

### การเดินทางไปชิงเหอ
- ออกจากจวนแบบฉุกเฉิน
- ใช้เวลา 5 วัน
- พบเหย่ชิงที่ตลาด
