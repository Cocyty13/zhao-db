# PLOT UPDATES

## อาจารย์ขององค์ชายรอง (ข้อมูลล่าสุด)
- **ชื่อ**: ไป๋หลาน และ เฟยหลง
- ระดับตำนานของง้อไป๊ บูตึ๊ง และยุทธภพ
- รักกันแต่ถูกกีดกัน
- ออกจากสำนักไปใช้ชีวิตด้วยกัน แล้วหายจากยุทธภพ
- รับองค์ชายรองเป็นศิษย์

## ลำดับศิษย์
- ไป๋หลาน + เฟยหลง → อาจารย์ขององค์ชายรอง
- เจ้าสำนักปัจจุบัน (อาจารย์อา) → อาจารย์ของเหย่ชิง
- องค์ชายรอง = ศิษย์หลาน
- เหย่ชิง = ศิษย์น้องตามลำดับรุ่น
