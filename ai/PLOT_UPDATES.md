# PLOT UPDATES (จุดสำคัญล่าสุด)

## การเดินทางถึงด่าน
1. เมืองหลวง → ค่ายหลงหยาง → เมืองชิงเหอ → เมืองหยานเฉิง → ด่านเหยียนเหมิน
2. นักยุทธ์จาก 5 สำนักมารวมที่หยานเฉิงแล้วติดตามมา

## ที่ด่านเหยียนเหมิน
- พบแม่ทัพหยาง
- แจ้งว่าทัพหลวงจะช้า (เตรียม ≈10 วัน + เดินทางเกือบเดือน)
- ไม่ยกธงมังกรขึ้นกำแพง
- นำข้าว 20 เกวียน / ช่าง / หมอ 10 / นักยุทธ์ ≈200 / ลูกธนูแบบใหม่ 1,000 ชุด
- ทดสอบลูกธนูหลี่หรง: ไกลและนิ่งกว่าในลมแรง
- สั่งสร้างเครื่องยิงหินหลังแนว + พรางเครื่องยิงบนกำแพง
- ปฏิบัติการข่าวลวงผ่านอู่จง (เสบียงทราย + ทัพหลวงมาแค่ 2,000) เพื่อให้สายลับพ่อค้าได้ยิน

## ประเด็นสำคัญ
- ชีเชี่ยอาจรีบบุกเพราะแหล่งน้ำแล้ง
- เป้าหมาย: ตั้งรับให้แข็ง + ทำให้ศัตรูดูเบา + รอทัพหลวง
