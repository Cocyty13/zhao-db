# PLOT UPDATES

## อาร์คแม่ทัพหยาง (สรุปสุดท้าย)

### จวนอู่
- ได้รับข่าวแม่ทัพหยางถูกตั้งโทษประหาร
- สอบจางเหลียงเรื่องเสบียงปนทราย
- ขอหน่วยเขี้ยวพยัคฆ์ + เข้าเฝ้าฮ่องเต้

### ด่านเหยียนเหมิน
- ปลอมตัวพ่อค้าพลอย
- เก็บหลักฐานกระสอบ + ทราย + บัญชี
- พบพยานนายกองจาง

### ลานประหาร
- กลับทัน ยิงธนูขัดขวาง
- หลี่หรง + หยางเฟยอยู่ที่เกิดเหตุ

### ท้องพระโรง
- เปิดหลักฐานทั้งหมด
- อ๋องฉีตัดหาง
- เจ้ากรมอาญาถูกลงโทษ
- ตั้งกรมสืบสวนพิเศษ

### หลังประชุม
- แม่ทัพหยางพ้นมลทินเบื้องต้น
- องค์ชายรองเริ่มมีอำนาจทางการเมือง
