# AI-Optimized Structure for Zhao Roleplay Database

## สำคัญมาก — อ่านก่อนใช้งาน

**ให้ใช้ข้อมูลจาก branch นี้เท่านั้น:**

```
ai-optimized-structure
```

อย่าอ่านจาก `main` เพราะข้อมูลจะเก่ากว่า

---

## วิธีเริ่มเล่นต่อ (สำหรับ AI ตัวอื่น)

1. สลับไปที่ branch `ai-optimized-structure`
2. อ่าน `ai/QUICK_FACTS.md` ก่อน (สั้นที่สุด สถานะปัจจุบัน)
3. อ่าน `ai/CORE_SNAPSHOT.md` + `ai/ACTIVE_PLOT.md`
4. **ถ้าต้องการประวัติทั้งหมดตั้งแต่ต้น** → อ่าน `ai/FULL_CANON_TIMELINE.md`
5. ถ้าต้องการรายละเอียดตัวละคร → เปิด `ai/CHARACTER_CARDS/`
6. เริ่มเล่นต่อจากฉากปัจจุบันได้เลย

---

## ไฟล์สำคัญเรียงตามลำดับความสำคัญ

| ลำดับ | ไฟล์ | ใช้เมื่อ |
|------|------|--------|
| 1 | `QUICK_FACTS.md` | เปิดฉากทันที รู้ว่าอยู่ตรงไหน |
| 2 | `CORE_SNAPSHOT.md` | สถานะปัจจุบัน + กำลัง + โทน |
| 3 | `ACTIVE_PLOT.md` | รายละเอียดฉากปัจจุบันและสิ่งห้ามย้อน |
| 4 | `FULL_CANON_TIMELINE.md` | **ประวัติทั้งหมดตั้งแต่ปกปิดตัวตนจนถึงปัจจุบัน** |
| 5 | `CHARACTER_CARDS/` | รายละเอียดตัวละครทีละคน |
| 6 | `ORGANIZATION/` | โครงสร้างกรมและฝ่ายยุทธภพ |
| 7 | `LOCATIONS/` | สถานที่สำคัญ |

## หลักการออกแบบ

### 3 ชั้นข้อมูล (Layered Knowledge)

| ชั้น | ชื่อไฟล์/โฟลเดอร์ | ความถี่ที่ AI ใช้ | คำอธิบาย |
|------|-------------------|------------------|----------|
| **L1** | `CORE_SNAPSHOT.md` + `QUICK_FACTS.md` | ทุกฉาก | สถานะปัจจุบัน |
| **L2** | `ACTIVE_PLOT.md` / `CHARACTER_CARDS/` / `FULL_CANON_TIMELINE.md` | บ่อย | รายละเอียดและประวัติ |
| **L3** | SQLite เดิม + ไฟล์ย่อยอื่น | นาน ๆ ครั้ง | ข้อมูลลึก |

### หลักการสำคัญ
- ไฟล์ในโฟลเดอร์ `ai/` เป็นชั้นที่ AI ควรอ่านก่อน
- ทุกการเปลี่ยนแปลงสำคัญควรอัปเดต CORE_SNAPSHOT และ ACTIVE_PLOT
- ประวัติทั้งหมดอยู่ใน `FULL_CANON_TIMELINE.md` — ห้ามให้เหตุการณ์ตกหล่น
