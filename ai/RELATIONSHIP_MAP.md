# แผนผังความเชื่อมโยงตัวละคร (Relationship Groups)

## 1. ราชวงศ์ / วังหลวง
- **ฮ่องเต้จ้าวหยวน**
- **ฮองเฮา**
- **รัชทายาทหลี่หยาง** + พระชายารัชทายาท
- **องค์ชายรอง** (ตัวเอก) + **หลี่หรง** (พระชายา)
- **องค์หญิงซัวเหยา** (น้องสาวองค์ชายรอง)

### ความสัมพันธ์สำคัญ
- องค์ชายรองเคยแสร้งเป็นคนเสเพลเพื่อปกปิดตัวตน
- คืนงานแต่งรัชทายาทเกิดเหตุลอบสังหาร → เปิดเผยตัว
- ฮองเฮาจัดงานชมบุปผา → ฮ่องเต้ประกาศราชโองการแต่งงานองค์ชายรอง-หลี่หรง

## 2. ตระกูลหยาง (คดีสำคัญปัจจุบัน)
- **แม่ทัพหยาง** (ถูกกล่าวหาถอยทัพ + เสบียงปนทราย)
- **หยางเฟย** (บุตรสาว ฉลาดหลักแหลม หอก ชุดเขียวริบบิ้นแดง)
- **พี่ชายของหยางเฟย** (รายละเอียดรอเติม)

### ความเชื่อมโยงกับตัวเอก
- หยางเฟยพบองค์ชายรองในงานชมบุปผา
- คดีของแม่ทัพหยางเป็นภารกิจหลักหลังแต่งงาน

## 3. สำนักฝีมือ / อาจารย์ขององค์ชายรอง
- **สิทธิ์** (สำนักเง้อ) – อาจารย์ / ศิษย์พี่ของเจ้าสำนัก
- **สิทย์** (สำนักบูตึ๊ง) – อาจารย์ / ศิษย์พี่ของเจ้าสำนัก
- องค์ชายรอง = ศิษย์หลาน

## 4. คนในจวนองค์ชายรอง
- **หลี่เชี่ย** (นางกำนัลอาวุโส / คนสนิท เรียกองค์ชายรองว่า “คุณชาย” แต่รู้สถานะจริง ใช้ราชาศัพท์แบบไม่พิธีมากเมื่ออยู่ด้วยกัน)
- **เสิ้นอวี้หลัน (CH-405)** – คนของหลี่หรง / นางกำนัล
- คนรับใช้และนางกำนัลอื่น ๆ ในจวน

## 5. กลุ่มทหาร / แม่ทัพอื่น
- **แม่ทัพอู่** + **ฮูหยินอู่** + **อู่เหวินเฉิง** (เคยปรากฏในฉากเยี่ยมจวนก่อนแต่งงาน)
- แม่ทัพและขุนนางที่เกี่ยวข้องกับแนวชายแดนตะวันตก

## 6. ตัวละครอื่นที่ปรากฏบ่อย
- **ซัวเหยา** (องค์หญิง น้องสาว – ชอบมาจวนพี่ชาย มักทำให้เกิดความวุ่นวายแบบน่ารัก)
- ตัวละครรองจากงานชมบุปผาและราชสำนัก (รอเติมจากฐานข้อมูล)
