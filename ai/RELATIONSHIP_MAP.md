# แผนผังความเชื่อมโยงตัวละคร (Relationship Groups)

## 1. ราชวงศ์ / วังหลวง
- **ฮ่องเต้จ้าวหยวน**
- **ฮองเฮา**
- **รัชทายาทหลี่หยาง** + **พระชายารัชทายาทเซี่ยหยุน**
- **องค์ชายรอง** (ตัวเอก) + **หลี่หรง** (พระชายา)
- **องค์หญิงซัวเหยา** (น้องสาวองค์ชายรอง)
- **อ๋องฉี** (เกี่ยวข้องกับคดีเสบียง)

### หมายเหตุ
- ไม่มีตัวละครชื่อ **อ๋องเจิ้ง** ในเรื่องนี้ (ถูกลบออกแล้ว)
- พระชายารัชทายาทชื่อ **เซี่ยหยุน** (ต้องจำให้ขึ้นใจ)

## 2. ตระกูลหยาง (คดีสำคัญ)
- **แม่ทัพหยาง**
- **หยางเฟย** (บุตรสาว ชุดเขียว + ริบบิ้นแดง อาวุธหอก)
- พี่ชายของหยางเฟย (รายละเอียดรอเติม)

## 3. สำนักฝีมือ / อาจารย์ขององค์ชายรอง
- **สิทธิ์** (สำนักเง้อ)
- **สิทย์** (สำนักบูตึ๊ง)
- องค์ชายรอง = ศิษย์หลาน

## 4. คนในจวนองค์ชายรอง
- **หลี่เชี่ย** (นางกำนัลอาวุโส / คนสนิท)
- **เสิ้นอวี้หลัน** – คนของหลี่หรง
- **อู่จง** และทหารใต้บัญชาจวนอ๋อง

## 5. กลุ่มทหาร / แม่ทัพอื่น
- **แม่ทัพอู่** + **ฮูหยินอู่** + **อู่เหวินเฉิง**
- หน่วยเขี้ยวพยัคฆ์

## 6. หน่วยงานและบุคคลในคดี
- กรมส่งกำลังบำรุง
- กรมอาญา (เจ้ากรมถูกถอดตำแหน่ง)
- ฝ่ายการท่า (แหล่งทราย)
- นายกองจาง (พยาน)
- ชายแผลเป็นคิ้วซ้าย (คนส่งเสบียง)
